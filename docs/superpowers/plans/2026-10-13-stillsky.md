# Stillsky Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Stillsky, a local-only night-sky focus timer (React Native CLI, iOS + Android) designed as a practice target for Appium and Mobilewright tests.

**Architecture:** Pure TypeScript domain modules (`src/domain`) hold every rule and are unit-tested with Jest. A typed AsyncStorage layer (`src/storage`) persists data, a single React Context (`src/state/AppProvider`) exposes state and actions, and thin screens render it with stable testIDs from `src/testIds.ts`.

**Tech Stack:** React Native CLI (latest stable) + TypeScript, React Navigation (native-stack + bottom-tabs), `@react-native-async-storage/async-storage`, `react-native-svg`, `react-native-reanimated` (+ `react-native-worklets` if the installed Reanimated major requires it), `@sayem314/react-native-keep-awake`, `react-native-sound`, Jest.

**Spec:** `docs/superpowers/specs/2026-10-13-stillsky-design.md`

## Global Constraints

- Repo root is the RN project root (`package.json` at `/Users/sylwia/Projects/mobile_app`).
- App display name `Stillsky`; iOS bundle ID and Android package `com.sylwia.stillsky`.
- No backend, no network calls, no login. All data in AsyncStorage.
- Storage values wrapped as `{ schemaVersion: 1, data }`; keys `user`, `settings`, `sessions`, `activeSession`.
- Settings defaults: `{ defaultDurationMin: 25, sound: true, keepAwake: true }`.
- Durations 10–120 min in 5-min steps; plus `1` only when `__DEV__`.
- Name valid when trimmed length (counted in code points) is 1–20.
- Tags: `work | study | reading | other` (labels Work / Study / Reading / Other), default `work`.
- Every interactive or asserted element has `testID` (from `src/testIds.ts`, never a literal) and `accessibilityLabel`.
- Screens contain no business logic; rules live in `src/domain`.
- Commit messages use type prefixes: `feat:`, `bugfix:`, `test:`, `chore:`, `docs:`.
- Keep-awake library: the spec names `react-native-keep-awake`; it is unmaintained, so use the maintained fork `@sayem314/react-native-keep-awake` (same API purpose).

## Review Focus

1. **App killed mid-session, reopened after the planned end** → session recorded as `completed` with `endedAt = startedAt + plannedMin`, not "now". (Test in Task 3.)
2. **Corrupt / foreign storage data** (invalid JSON, wrong `schemaVersion`, wrong shape) → defaults, no crash. (Test in Task 6.)
3. **Names that only look valid** — whitespace-only, 21 code points, emoji (`"🌟🌟"` is 2, not 4) → validation matches what the user sees. (Test in Task 2.)
4. **Sessions stored out of order** (seeded data, clock changes) → stars light in order of `endedAt`, constellation completion date is correct. (Test in Task 4.)
5. **Period edges** — session at 23:59 Sunday vs 00:00 Monday, February month (28 bars), a failed session never adds minutes. (Test in Task 5.)
